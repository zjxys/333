🖼️ 图片转文字

上传一张包含文字的图片，自动识别并提取文字内容。支持中英文识别。

💡 基于 Tesseract.js 引擎，纯前端运行，图片不会上传到服务器，保护隐私。
📁
点击选择图片，或拖拽图片到这里
支持 PNG / JPG / JPEG / BMP / WebP

🎤 语音转文字

点击麦克风按钮开始说话，系统会自动将语音转换为文字。支持中文识别。

💡 基于 Web Speech API，建议使用 Chrome 或 Edge 浏览器。需要允许麦克风权限。
